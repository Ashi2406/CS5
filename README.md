# TRT Cast V2

This build adds a real-time MJPEG HTTP stream using Android MediaProjection.

Test:
1. Install the APK.
2. Connect phone and a second device to the same Wi-Fi.
3. Tap START CAST and allow screen sharing.
4. Open `http://PHONE_IP:8080/` on the second device.

This is a receiver/browser test. It is not a claim of native Mahindra CarPlay/Android Auto integration.
